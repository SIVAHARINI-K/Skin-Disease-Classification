# 🩺 Skin Disease Classification Using Deep Learning

## 📌 About the Project
This project uses a Convolutional Neural Network (CNN) to classify skin disease images. It provides a simple web interface built with Streamlit for uploading images and displaying predictions.

## 🎯 Objectives
- Classify skin disease images using deep learning.
- Apply CNN for image classification.
- Provide a simple and user-friendly interface.
- Explore deep learning applications in healthcare.

## 🛠️ Technologies Used
- Python
- TensorFlow / Keras
- OpenCV
- Streamlit
- NumPy
- Pillow

## ✨ Features
- Upload a skin image.
- Preprocess the image.
- Predict the skin disease category using a trained CNN model.
- Display the prediction through a Streamlit interface.

## 📂 Project Files
- `app.py` – Streamlit application.
- `train_model.py` – CNN model training.
- `skin_disease_model.h5` – Trained model.
- `label_encoder.pkl` – Label encoder.
- `requirements.txt` – Required Python libraries.
